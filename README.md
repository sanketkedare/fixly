# Fixly - Service Provider App

Fixly is a mobile-first application for booking household and professional services.

## Tech Stack
- **Next.js 15**
- **Tailwind CSS**
- **Mongoose / MongoDB**
- **Firebase Auth**
- **React Query**
- **Framer Motion**

## Getting Started

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Setup environment variables**:
   Create a `.env.local` file (already initialized with placeholders).

3. **Run the development server**:
   ```bash
   npm run dev
   ```

## Project Features
- Mobile-optimized UI
- Smooth animations
- Service booking flow
- User bookings dashboard
